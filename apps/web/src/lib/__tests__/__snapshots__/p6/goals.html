目标

短期与长期目标、当前状态、进度与里程碑。进度与勾选状态全部来自 content/goals 下的 frontmatter。

短期SHORT TERM

  • 示例目标：短期（请替换）

    计划中2026 Q4
    0%
    • 第一个里程碑（请替换）（未完成）
    • 第二个里程碑（请替换）（未完成）

    这是占位内容。 progress: 0 只表示「还没有填写真实进度」， 不代表任何已经完成的工作。请替换成你自己的目标与真实数据。

    为什么定这个目标

    写清楚动机，以及「做到什么程度算完成」。

    计划怎么做

    • 第一步
    • 第二步
    • 第三步

    判断标准

    写下可验证的完成标准，避免目标永远停在「进行中」。

长期LONG TERM

  • 示例目标：长期（请替换）

    计划中2027 -
    0%
    • 长期里程碑（请替换）（未完成）

    这是占位内容。 请替换成你自己的长期目标。

    长期方向

    长期目标只写方向与原则，不写具体时间表。

    与短期目标的关系

    说明这个长期目标如何被短期目标逐步推进，避免两者脱节。
